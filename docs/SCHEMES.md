## Nationwide matching

- Scheme with `states: ["Kerala"]` (etc.) only matches that state.
- Scheme with empty `states`, or `states` including `"All India"` / `"India"`, or `nationwide: true`, matches any profile state.
- Profile `state` is required; missing state → uncertain (`miss`), not a silent Kerala assumption inside the rule engine (API still defaults omitted state to Kerala for backward compatibility).
